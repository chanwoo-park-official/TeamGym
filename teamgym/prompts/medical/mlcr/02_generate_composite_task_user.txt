Rules:
1. The public question asks the participant to answer the clinical task, not identify

3. Every used source QA must contribute at least one selected candidate and required

4. Preserve separate evidence contributions. Multiple RIUs may jointly support one
   claim, and one RIU may support multiple claims.

7. The reference answer must satisfy all claims using only selected source evidence.
8. Generic medical knowledge may connect observations but cannot replace missing
   patient-specific evidence.

   detail in the rubric unless the public question explicitly asks for that type of
   detail. For example, a generic request for injury mechanism should not silently
   require every scene detail (such as airbag deployment); either ask for that detail

10. If the ALL solver misses a rubric detail that the public question did not clearly
    request, revise the rubric/question alignment rather than merely repeating the
    same hidden detail in the reference answer.
